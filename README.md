
# College Campus Assistant Chatbot

## Description

The **College Campus Assistant Chatbot** is an AI-powered chatbot developed using **Botpress**. It helps students, parents, and visitors quickly get information related to college services.

The chatbot provides instant responses to common queries such as admission process, available courses, examination schedules, library timings, and college contact information.


##  Features

- ✅ Admission Information
- ✅ Course Details
- ✅ Exam Schedule Information
- ✅ Library Timings
- ✅ Contact Information
- ✅ User-friendly conversation flow
- ✅ 24/7 automated support
- ✅ Fallback handling for unknown queries


##  Technology Used

- **Botpress**
- **Conversational AI**
- **Natural Language Processing (NLP)**


##  Use Case

This chatbot works as a virtual college assistant that reduces manual work for administration staff and provides quick answers to frequently asked student queries.
